Privacy policy

Last updated: 2026-10-08

OpenClaw Edge Connect is a personal app used only by its developer and owner. It accesses only the owner's own Google account.

What it accesses

With the owner's consent it reads and manages the owner's Gmail messages and Google Calendar events (scopes https://mail.google.com/ and https://www.googleapis.com/auth/calendar).

How data is used and stored

Data is used only to show the owner their own mail and calendar and to act on the owner's instructions. The OAuth refresh token is kept in a private configuration file on the owner's own server. Mail and calendar content is not sold, shared with third parties, used for advertising, or used to train machine-learning models.

Retention and revocation

The owner can revoke access at any time at myaccount.google.com/permissions, after which the stored token stops working and is deleted.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
